Place plugin icons here (PNG or SVG):
  icon.png            - main plugin icon (referenced by metadata.txt)
  setup.svg           - Setup panel toolbar action
  rainfall.svg        - Precipitation Assessment module
  classification.svg  - Land-System Classification module

If any icon file is missing, the plugin falls back to a built-in QGIS
icon automatically (see savana_plugin.py / registry.py), so the plugin
still loads and works without them.
