about=Savana brings the savana Python package into QGIS as a set of dockable
    analysis panels under one hub.

    Choose an analysis type from the hub launcher and its own panel opens
    with its own controls:

    Land-System Classification:
    - Adaptive, percentile-derived classification of savanna landscapes into
      ecologically meaningful structural classes for any AOI
    - Multi-epoch mapping and RUE-validated change detection

    Precipitation Product Assessment:
    - Zone-stratified validation of global precipitation products (CHIRPS,
      ERA5-Land, GPM IMERG, MERRA-2, PERSIANN-CDR, TerraClimate) against
      GPCC gauge observations
    - Application-weighted decision matrix for product selection

    Shared:
    - One-click managed Python environment installer for the savana package
      and its Earth Engine dependencies (kept isolated from QGIS's own Python)
    - A single Google Earth Engine connection, set once and used by every panel

    Requires a Google Earth Engine account with a registered Cloud project.
